# VIT Pune AI Agent - Capstone Project Group 7

> Generative AI Agent for University Student Support
> Built with RAG + LangChain + LLaMA3 + ChromaDB + Streamlit

---

## Project Structure

```text
university_ai_agent/
|-- src/                         # Application source code
|   |-- app.py                   # Streamlit interface
|   `-- rag_engine.py            # Retrieval and AI-agent logic
|-- data/                        # Versioned knowledge-base files
|   |-- university_data.txt
|   |-- feedback.csv
|   `-- deadlines.txt
|-- tests/                       # Automated tests
|   `-- test_rag_engine.py
|-- vectorstore/                 # Generated locally; excluded from Git
|-- .env.example                 # Environment-variable template
|-- requirements.txt
|-- README.md
`-- .gitignore
```

Notes:
- `src/` contains application code and `tests/` contains automated checks.
- `data/` stores the source files used by the app.
- `vectorstore/` is auto-generated by ChromaDB when the agent is initialized.
- `__pycache__/` and similar cache folders should not be kept in the project structure.

## Setup

### Prerequisites

Install the following before starting:

- [Python 3.10 or later](https://www.python.org/downloads/)
- [Ollama](https://ollama.com/) to run the Llama 3 model locally
- Git (only required when cloning the repository)

Verify the installations from a terminal:

```bash
python --version
ollama --version
```

### 1. Get the project

Clone the repository, or open the existing project folder in a terminal:

```bash
git clone <repository-url>
cd university_ai_agent
```

### 2. Create and activate a virtual environment

Using a virtual environment keeps project dependencies separate from your system Python.

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

> If PowerShell blocks activation, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` once in that terminal, then activate the environment again.

### 3. Install Python dependencies

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

### 4. Configure the local language model

Download the default model used by the application:

```bash
ollama pull llama3
```

Ollama normally starts automatically after installation. If it is not running, start it in a separate terminal:

```bash
ollama serve
```

### 5. Configure environment variables (optional)

Create your local configuration file. It is ignored by Git, so do not commit it.

**Windows PowerShell:**

```powershell
Copy-Item .env.example .env
```

**macOS / Linux:**

```bash
cp .env.example .env
```

The default configuration is already suitable for most users. To use a different installed Ollama model, update `.env`:

```env
OLLAMA_MODEL=llama3
```

### 6. Start the application

Run this command from the project root, with the virtual environment active:

```bash
streamlit run src/app.py
```

Open `http://localhost:8501` if Streamlit does not open the browser automatically.

### 7. Initialize the knowledge base

In the application sidebar, select **Initialize Agent**. On the first run, the app reads files in `data/`, generates embeddings, and creates a local `vectorstore/` directory. Later runs reuse that stored index.

## Troubleshooting

- If Ollama is not running, start it with `ollama serve`.
- If the model is missing, run `ollama pull llama3`.
- If port `8501` is busy, run `streamlit run src/app.py --server.port 8502`.

## Testing

Run the smoke-test suite from the project root:

```bash
python -m unittest discover -s tests -v
```
